I wanted a digital space that truly felt like *me*—not just another generic template. This site serves as a central hub for all my projects, writings, and travels. 

### Tech Stack
- **Framework**: Astro (for ultra-fast static generation)
- **Styling**: Tailwind CSS v4 with custom earth-tone variables
- **Interactive Maps**: React-Leaflet
- **Content**: Markdown and MDX Collections

It's entirely open-source and deployed automatically via Cloudflare Pages whenever I push to the main branch.
